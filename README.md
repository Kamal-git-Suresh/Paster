# Paster
A simple quality of life tool for windows that let's you paste text from the clipboard into textboxes that explicitly block pasting.

### Install 
This can be done in two ways
1. By cloning the repo
  +  Clone this repository ``` git clone https://github.com/Kamal-git-Suresh/Paster ```
  +  Convert the python file into an executable using [auto-py-to-exe](https://pypi.org/project/auto-py-to-exe)
  +  Then run install.bat
2. Directly downloade the executable from [releases](https://github.com/Kamal-git-Suresh/Paster/releases/tag/Release)
   + Follow the instructions on the release page

### How to use
After installing, the shortcut ctrl + ` will trigger it.

### How it works
It simple simulates keystrokes for the characters in the clipboard so as far as the textbox is concerned, it was typed by the user.
